# Reporting a security issue

Use **Report a vulnerability** in the repository’s Security tab when available. If the button is unavailable, open an issue asking the maintainer for a private reporting channel. Share technical details, affected versions and redacted logs in that private channel. Keep credentials, setup codes and QR images private.

The [security guide](docs/security.md) describes the panel’s network and firmware-update assumptions. Revoke an exposed panel key in Bambuddy.
